# Moneyology standalone v1

This branch is an original Moneyology implementation and does not use the Ultimate Paycheck Budget App codebase.

Included in the first standalone foundation:
- Moneyology branding and logo
- Supabase email/password sign-in
- automatic per-user cloud sync through `user_budget_state`
- Dashboard
- Transactions with a dedicated Subscriptions bucket
- Bi-weekly frequency as a direct option
- Accounts (no Investments section)
- Savings buckets and progress
- Debt records with separate original and current balances plus lifetime progress
- responsive mobile navigation

Next planned work: paycheck calendar/assignment workflow, transaction editing/deleting, debt payment history and payoff calculations, recurring schedule generation, historical import/migration tooling, and fuller PWA install polish.
